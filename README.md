# ExchangeRateETL

A learning project that will ingest currency exchange rates from a public API, validate and transform the data with Python, and load it into Microsoft SQL Server.

## Planned data flow

Public API → Python extraction → JSON parsing → validation and transformation → SQL Server → SQL analysis

## Planned tools

- Python
- REST API and JSON
- SQL Server and `pyodbc`
- `requests`
- `python-dotenv`
- `logging`
- `pytest`
- Git and GitHub

## Project status

In progress. This project is being built step by step as a practical Data Engineering learning project.
